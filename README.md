# Warning Label for Humans: One Line, Big Laugh

A single-line safety warning label that should come printed on every human
being — funny first, plausible second. The program writes exactly one line
to `/output/entry.txt`.

## Entry

> WARNING: This human will confidently explain things it learned five minutes
> ago. Keep away from microphones, group chats, and Thanksgiving.

## Run

```sh
node main.ts
```

It writes the label to `/output/entry.txt` (one line, under 160 characters).
